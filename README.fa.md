# نیوورا

**نیوورا** یک لانچر بومی ویندوز برای Antigravity App، IDE و CLI است. برای کاربرانی طراحی شده که در مناطقی زندگی یا روی شبکه‌هایی کار می‌کنند که دسترسی به Antigravity در آن‌ها محدود است. نیوورا نسخهٔ نصب‌شدهٔ Antigravity را با پراکسی محلی HTTP یا SOCKS5 اجرا می‌کند. دسترسی نهایی به سرویس به شبکه، شرایط حساب و محدودیت‌های ارائه‌دهنده بستگی دارد.

[**دانلود نسخهٔ نصبی ویندوز ۶۴ بیتی**](https://github.com/PersianArtStudio/Nivora/releases)

پراکسی محلی‌ات را روشن کن، برنامهٔ موردنظر را انتخاب کن و **Launch selected target** را بزن. نیوورا پاسخ پراکسی را بررسی می‌کند، برنامه را اجرا می‌کند و می‌تواند به بخش اعلان‌های کنار ساعت ویندوز منتقل شود. مسیر فایل اجرایی هر گزینه جداگانه ذخیره می‌شود.

## نصب در ویندوز

در ریلیز `v1.1.0`، از بخش **Assets** فایل `Nivora-Setup-1.1.0-x64.exe` را دانلود و اجرا کن. به ویندوز ۱۰ یا ۱۱ نسخهٔ ۶۴ بیتی، نسخهٔ موردنظر Antigravity و یک پراکسی محلی فعال نیاز داری.

نصب‌کننده برای حساب فعلی یک میان‌بر در منوی Start می‌سازد. ساخت میان‌بر روی دسکتاپ اختیاری است. برای حذف برنامه از **Windows Settings → Apps** استفاده کن. اگر می‌خواهی نصب‌کننده را خودت بسازی، سورس پروژه و ابزارهای بخش «ساخت نصب‌کننده» را لازم داری.

## انتخاب برنامه برای اجرا

| گزینه در داشبورد | چه چیزی باز می‌شود | نحوهٔ تنظیم |
| --- | --- | --- |
| Antigravity App | برنامهٔ مستقل دسکتاپ | تشخیص خودکار یا انتخاب `Antigravity.exe` |
| Antigravity IDE | ویرایشگر مستقل | تشخیص خودکار یا انتخاب `Antigravity IDE.exe` |
| Antigravity CLI | ترمینال تعاملی با اجرای `agy` | CLI را نصب کن، در صورت نیاز `agy.exe` را انتخاب کن و هنگام هر اجرا پوشهٔ پروژه را مشخص کن. |
| Editor with Antigravity extension | ویرایشگر نصب‌شدهٔ خودت | افزونه یا اتصال Antigravity را در ویرایشگر تنظیم کن و فایل اجرایی معتبر ویرایشگر را در **Settings** انتخاب کن. |

ابتدا برنامهٔ موردنظر را روی داشبورد انتخاب کن، سپس برای تعیین مسیر به **Settings → Browse** برو. اگر برنامه از قبل باز است، قبل از اجرای دوباره آن را ببند تا تنظیمات پراکسی به فرایند جدید برسد. هر نشست یک برنامه را مدیریت می‌کند. برای توقف یا راه‌اندازی مجدد از آیکن نیوورا کنار ساعت استفاده کن. قبل از توقف، کارت را ذخیره کن.

## ساخت نصب‌کننده

روی کامپیوتر ویندوز ۶۴ بیتی که قرار است بیلد بگیرد، Python 3.7 یا جدیدتر همراه pip و Inno Setup 6.3 یا جدیدتر از سری ۶ را نصب کن. اگر Zig 0.13.0 در دسترس باشد، اسکریپت همان را استفاده می‌کند. در غیر این صورت، بستهٔ حدود ۸۰ مگابایتی کامپایلر ویندوز را دانلود می‌کند، SHA-256 آن را بررسی می‌کند و آن را در پوشهٔ `.build-tools` پروژه نگه می‌دارد. نیازی به تغییر PATH سیستم نیست. برای ساخت آفلاین، فایل `ziglang-0.13.0-py3-none-win_amd64.whl` را کنار فایل BAT بگذار. اگر Inno Setup را در مسیر سفارشی نصب کرده‌ای، متغیر `ISCC` را روی مسیر کامپایلر آن تنظیم کن.

1. سورس را در پوشه‌ای که دسترسی نوشتن داری استخراج یا Clone کن.
2. روی `Build-Installer.bat` دوبار کلیک کن.
3. فایل `dist/Nivora-Setup-1.1.0-x64.exe` را همراه `SHA256SUMS.txt` منتشر کن.

کامپایلر و ابزار ساخت نصب‌کننده فقط روی سیستم سازنده لازم‌اند. گردش‌کار ویندوز در GitHub Actions نصب‌کننده را می‌سازد و بازشدن داشبورد، نصب و حذف را بررسی می‌کند. تگ نسخه پس از ساخت موفق، انتشار Release را فعال می‌کند. خروجی انتشار شامل نصب‌کننده و فایل هش آن است. فایل‌های اجرایی تولیدشده در Git نگهداری نمی‌شوند.

## اتصال و حریم خصوصی

نیوورا پراکسی‌های محلی HTTP و SOCKS5 بدون احراز هویت را روی آدرس IPv4 لوپ‌بک بررسی می‌کند. برای تنظیم دستی، نوع پراکسی و پورت را در **Settings** انتخاب کن. App و IDE پارامتر پراکسی Chromium را دریافت می‌کنند. متغیرهای محیطی پراکسی هم فقط به فرایند برنامهٔ انتخاب‌شده و فرایندهای فرزند آن داده می‌شوند. در CLI و ویرایشگرهای دیگر، عبور ترافیک به پشتیبانی خود برنامه، افزونه و فرایندهای فرزند بستگی دارد. بررسی موفق یعنی پراکسی محلی پاسخ داده است. ورود به حساب از مسیر عادی خود Antigravity انجام می‌شود.

گزینهٔ **Activity → Export** رویدادهای فیلترشده را ذخیره می‌کند. تنظیمات در `HKCU/Software/Nivora` و فایل‌های گزارش در `%LOCALAPPDATA%/Nivora` قرار دارند. اجرای خودکار هنگام ورود به ویندوز و اعلان‌ها قابل تنظیم‌اند. بعد از حذف برنامه، تنظیمات و گزارش‌ها باقی می‌مانند.

## عیب‌یابی

- **برنامه پیدا نمی‌شود**. فایل اجرایی را در **Settings** انتخاب کن. برای CLI، مسیرهای مطلق ثبت‌شده در PATH و پوشه‌های رایج نصب کاربر بررسی می‌شوند.
- **پراکسی پاسخ نمی‌دهد**. پراکسی‌کلاینت را روشن کن و شمارهٔ پورت محلی را بررسی کن. یک وب‌سرور محلی هم ممکن است به آزمون HTTP پاسخ بدهد.
- **ویرایشگر باز می‌شود ولی Antigravity دیده نمی‌شود**. افزونهٔ مربوط را نصب و فعال کن یا ACP را در ویرایشگر تنظیم کن. گزینهٔ ویرایشگر، خود ویرایشگر را اجرا می‌کند.
- **نشست CLI بسته می‌شود**. نشست تازه‌ای شروع کن و پوشهٔ پروژه‌ای را انتخاب کن که به آن دسترسی داری. ترمینال همراه فرایند CLI بسته می‌شود.
